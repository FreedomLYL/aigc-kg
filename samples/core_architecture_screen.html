①输入

文档上传解析预处理模块

非结构化 PDF / Word / Markdown —— 解析、清洗、分块，转成可抽取的统一文本

②抽取

AIGC 知识抽取模块 ├ 实体识别 · 关系抽取

从文本中识别知识点实体与其语义关系，输出结构化三元组

③存储

Neo4j 图数据库读写模块

三元组写入图库，支持节点/关系的增删改查与图遍历

④可视化

交互式知识图谱可视化模块

前端渲染节点网络：拖拽、缩放、高亮、编辑一体化交互

⑤应用

教师 Web 端界面 ├ 课程管理 · 图谱编辑

教师建课、上传文件、编辑与维护课程知识图谱

⑥应用

学生 Web 端界面 ├ 图谱浏览 · 掌握标记 · 路径推荐

学生浏览图谱、标记掌握情况、获取个性化学习路径

⑦问答

RAG 智能问答模块

基于图谱+文档检索增强，面向具体问题生成可溯源的答案
